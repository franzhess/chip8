# Historical ROM collection

These ROMs were already included in the original repository. They are programs written by their respective authors, separate from the Rust emulator.

| Directory | Contents |
| --- | --- |
| `games/` | Games such as Pong, Tetris, and Space Invaders |
| `demos/` | Graphics demonstrations |
| `programs/` | Logos, utilities, and diagnostic programs |
| `hires/` | Original VIP 64×64 programs; unsupported by this emulator |

Names and dates in the filenames are preserved as supplied. Companion `.txt` files contain the original instructions and author notes. For example, the collection credits Paul Vervalin for Pong, Fran Dachille for Tetris, David Winter for multiple games, and Revival Studios for several demos and games. See individual files for the full credits.

The default embedded program is `programs/Chip8 Picture.ch8`; the headless smoke test uses `programs/IBM Logo.ch8`.

The original collection's download source and a collection-wide license were not recorded in this repository. Existing author notes are retained; no new authorship or licensing claims are made for these ROMs.
